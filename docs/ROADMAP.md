# Roadmap

The first release intentionally focuses on local, source-grounded typing practice.

## Next

- Daily goals with configurable WPM, accuracy, time, or set targets.
- Export and import for the SQLite history, sources, and settings.
- Optional virtual-keyboard and hand-guide visibility controls.

## Later

- Additional keyboard layouts.
- Optional external content-generator integrations. AI remains outside the core app unless explicitly enabled by the user.
- Packaged desktop distribution if a one-click installer becomes more valuable than the browser-based local workflow.
